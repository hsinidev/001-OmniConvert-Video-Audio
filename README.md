## 📌 Description
OmniConvert is an enterprise-grade multimedia transcoder engine designed for high-throughput video and audio format conversion, codec reconfiguration, and media optimization.

---

## ✨ Features
- Multi-format hardware-accelerated video & audio transcoding (MP4, MKV, AVI, MP3, AAC, FLAC)
- Custom resolution scaling, bitrate tuning, and frame-rate adjustment
- Batch queuing with real-time progress, ETA calculation, and thread allocation
- Sub-process isolation for ffmpeg/ffprobe core engines with error recovery
- Intuitive modern desktop user interface built with PySide/PyQt

---

## 🛠️ Tech Stack & Architecture
- **Language / Framework**: Python 3.10+ / Qt (PySide6 / PyQt)
- **Core Modules**: Modular engine architecture, async event dispatching, decoupled utility functions
- **Target OS**: Windows, macOS, Linux

## 🚀 Quick Start & Installation

### Prerequisites
- **Python**: Version 3.10 or higher installed
- **Git**: Installed for cloning repositories

### Setup Instructions
```bash
# 1. Clone the repository
git clone https://github.com/hsinidev/OmniConvert-Video-Audio.git

# 2. Navigate to project directory
cd OmniConvert-Video-Audio

# 3. Install required dependencies
pip install -r requirements.txt

# 4. Launch the Application
python app.py
```
*(Note: If `app.py` is absent, launch with `python main.py`)*
